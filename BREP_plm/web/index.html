                Part types

                Each type has its own numbering. A counter type adds a prefix to a zero-padded number that counts up. A free text type takes any number the user types, such as an ERP purchasing number. A pattern type takes a typed number that must match a regular expression. A script type asks one of the administrator's scripts. In every mode, a part number is unique across all parts.

                Bake queue

                Server bake worker Checking…

                These controls manage this server's worker. Stopping preserves the queue. An interrupted job can be taken back below, or will become available when its claim expires. Workers started elsewhere are managed separately.

                A family member or a spin-out assembled by the server waits here until a headless CAD worker (a user in the worker group) claims it, checks and rebuilds it, and writes it back. A claim lapses after 15 minutes, so a worker that stops never strands a job. A failed job waits for a person: fix the row or the template, then retry it. Saving the part from the CAD app also answers its bake.

                Scripts

                About server scripts

                Scripts are JavaScript files in a folder on the server: . That folder is the source of truth. You can keep it in git, and the server picks up a changed file on its next call, with no restart. This editor reads and writes the same files.

                FileFunctionWhen it runs

                A hook that throws refuses its operation, and the user sees the thrown message. The one exception is afterRelease: it runs after the release is committed, so a throw is shown as a warning and the release stands. Scripts are fully trusted. They can use http, fs, process and plm.

                  Backups
                  
    
                  A backup is one .tar.gz: a snapshot of the database, every
      revision's document, every attachment and the scripts directory, with a manifest of
      their hashes. The server holds writes off for the few milliseconds the snapshot takes,
      so a backup is consistent while people work. Restore one with
      brep-plm restore --from <file> --data <new directory>.

                  Security
                  
    
                  Sign-in lockouts
                  
    
                  After 5 failed sign-ins for one username, or 20 from one address, that
      username or address is refused for 30 seconds. Each further failure doubles the wait,
      up to 15 minutes. A success clears the username's count. The counts are kept in
      memory, so a restart clears them too.
