            Part types

            Each type has its own numbering. A counter type adds a prefix to a zero-padded number that counts up. A free text type takes any number the user types, such as an ERP purchasing number. A pattern type takes a typed number that must match a regular expression. A script type asks one of the administrator's scripts. In every mode, a part number is unique across all parts.

            Bake queue

            The server never runs the CAD kernel. A member or a spin-out the server assembled waits here until a headless CAD worker (a user in the worker group) claims it, checks and rebuilds it, and writes it back. A claim lapses after 15 minutes, so a worker that stops never strands a job. A failed job waits for a person: fix the row or the template, then retry it. Saving the part from the CAD app also answers its bake.

              Backups
              
    
              A backup is one .tar.gz: a snapshot of the database, every
      revision's document, every attachment and the scripts directory, with a manifest of
      their hashes. The server holds writes off for the few milliseconds the snapshot takes,
      so a backup is consistent while people work. Restore one with
      brep-plm restore --from <file> --data <new directory>.

              Sign-in lockouts

      username or address is refused for 30 seconds. Each further failure doubles the wait,
      up to 15 minutes. A success clears the username's count. The counts are kept in
      memory, so a restart clears them too.
